# Plugin development

The authoritative plugin SDK, field contracts, examples, packaging CLI and server host moved to [taskasaur-server](https://github.com/taskasaur/taskasaur-server/tree/main/docs/plugins). This repository contains the browser plugin adapter, shared UI components and Dexie/synchronization adapters. They consume the pinned `@taskasaur/platform` package from `vendor/`. See [repository separation](../repository-separation.md) for the SDK update workflow.
